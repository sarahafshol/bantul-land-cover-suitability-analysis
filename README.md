# Bantul Land Cover Change & Land Suitability Analysis

## Project Overview

This project reconstructs a previous remote sensing and Geographic Information Systems (GIS) research project focused on coastal land cover change and land suitability in Bantul Regency, Yogyakarta, Indonesia.

The project explores how geospatial analysis can support environmental assessment, coastal land management, and sustainable land-use planning.

## Research Background

The project builds on the research:

**Land Cover Change and Land Use Suitability Analyses of Coastal Area in Bantul District, Yogyakarta, Indonesia (2019).**

Original research publication: https://doi.org/10.13057/biodiv/d200541

## Objectives

- Explore land cover classification in a coastal landscape.
- Investigate land cover and land-use changes over time.
- Explore GIS-based land suitability analysis.
- Reconstruct selected analyses using accessible spatial data and QGIS.
- Document methods, findings, and data limitations transparently.

## Study Area

Bantul Regency, Special Region of Yogyakarta, Indonesia.

The analysis will focus on the coastal landscape, subject to the availability of suitable spatial data.

## Tools & Technologies

- QGIS
- Remote sensing imagery and spatial datasets
- GIS overlay and spatial analysis
- GitHub for project documentation and version control

## Project Status

**Status:** In progress

This is a reconstruction of previous research. Original spatial datasets are no longer available, so the reconstructed analysis may use alternative data sources and methods. Results may differ from the original publication.

## Planned Outputs

- Study area map
- Land cover classification map
- Land cover change analysis, if suitable multi-temporal data are available
- Land suitability analysis, subject to data availability
- Methodology and limitations documentation
